## 🏃 Quick Start (Windows)
Double-click `start_all.bat` to launch both backend and frontend:
- **Frontend Dashboard**: `http://localhost:5173`
- **DRF Backend API**: `http://localhost:8000/api/`

To run automated unit tests:
Double-click `run_tests.bat` or run:
```cmd
cd "cleandesk ai task\backend"
python manage.py test api -v 2
```

For full documentation and API specifications, see `cleandesk ai task/README.md`.
